# Python Code Refactoring Project

## Project Overview
This project is part of my CST 205 Introduction to Python Programming course at Concordia University, St. Paul.

The purpose of this assignment is to improve an existing Python script by making the code easier to read, understand, and maintain while keeping its original functionality.

## What the Program Does
The program processes a list of numbers and a list of strings.

- Numbers are multiplied by 2 if they are even and by 3 if they are odd.
- Strings with five or more characters are converted to uppercase.
- Shorter strings are converted to lowercase.

## Project Files
- `undocumented_script.py` — The Python script.
- `CODE_REVIEW.md` — My original observations and final evaluation.
- `DECISIONS.md` — Explanations of my refactoring decisions.
- `README.md` — Project information and instructions.

## How to Run the Program
1. Download or clone this repository.
2. Make sure Python 3 is installed.
3. Open `undocumented_script.py` in Python IDLE or another Python editor.
4. Run the program using **Run Module (F5)**.

Alternatively, open a terminal in the project folder and run:

`python3 undocumented_script.py`

## Expected Output
```
Processed Numbers: [3, 4, 9, 8, 15, 12, 21]
Processed Strings: apple BANANA kiwi GRAPEFRUIT CHERRY
```

## Project Goal
My goal is to demonstrate how meaningful variable names, function documentation, and simple refactoring techniques can make Python programs easier for other developers to understand and maintain.
